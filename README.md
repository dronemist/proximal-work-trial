# Proximal Work Trial

## Task 1 — Design-to-Code RL Environment

A scalable pipeline for generating RL environments that test coding agents' ability to replicate multi-page website designs from screenshots. Generates websites from scratch, packages them as [Harbor](https://harborframework.com/) tasks, and grades agent output with a continuous multi-axis reward signal suitable for RL training.

Includes 13 ready-to-run tasks, an 8-metric grading system (pixel, structural, semantic, visual), anti-cheat detection, and evaluation results from Opus runs.
